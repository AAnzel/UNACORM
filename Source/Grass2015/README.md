# dna_encoding

Programming recommendations

1.Every function needs to be thoroughly documented and easy to understand. Use Docstring Conventions as a template.

2.Code formatting must follow PEP 8 style convention. This can be easily achieved using some IDE with a PEP 8 extension. I can recommend VSCodium as it has integrated (but disabled by default) PEP 8 code check.

3.Benchmark data set will be created in the near future, and you will have to adapt your input/output according to that data set. Until then, test your tool on some synthetic data from the relevant paper for your code.

4.Use git for version control. Use GitHub (preferred) or GitLab to save your work in a repository. Repositories have to be private while the project lasts, and after that you are allowed to change their visibility. Every repository must have a Wiki that documents in detail the whole algorithm.
